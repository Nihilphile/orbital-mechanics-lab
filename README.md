# Orbital Mechanics Lab

Two interactive, self-contained HTML demonstrations.

- [ECI → Perifocal](https://nihilphile.github.io/orbital-mechanics-lab/eci-perifocal.html)
- [Orbits & Ground Tracks · 轨道与地面轨迹](https://nihilphile.github.io/orbital-mechanics-lab/ground-track.html)

[Open the project homepage](https://nihilphile.github.io/orbital-mechanics-lab/).

The demonstrations run directly in the browser. No installation is required.

## Publishing

GitHub Pages serves the root of the `main` branch. To update a demonstration, edit its HTML file and push to `main`.
